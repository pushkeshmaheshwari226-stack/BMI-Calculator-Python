# BMI Calculator 🏋️

A beginner Python project that calculates Body Mass Index (BMI) based on user input and returns a health classification.

## 📌 Project Overview

This script takes a user's name, weight (in pounds), and height (in inches), computes their BMI using the standard formula, and outputs a personalized health category message.

**Formula used:**
BMI = (Weight in lbs × 703) / (Height in inches)²

## 🏷️ BMI Categories

| BMI Range | Classification |
|-----------|---------------|
| < 18.5 | Underweight |
| 18.5 – 24.9 | Normal Weight |
| 25.0 – 29.9 | Overweight |
| 30.0 – 34.9 | Obese |
| 35.0 – 39.9 | Severely Obese |
| ≥ 40.0 | Morbidly Obese |

## 🛠️ Tools & Skills

- Python 3

## ▶️ How to Run

1. Clone this repository
2. Open `BMI_Calculator.ipynb` in Jupyter Notebook
3. Run the cell and enter your name, weight, and height when prompted
